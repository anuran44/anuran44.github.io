Selected Research

AI-Powered Fact Verification System

RQ: How can adaptive retrieval strategies reduce inference costs while maintaining high factual accuracy in language reasoning models?
Problem

Static Retrieval-Augmented Generation (RAG) pipelines often waste computational resources on redundant document retrieval during evidence-based claim verification, limiting the scalability of human-centered fact-checking tools.

Method

Developed a retrieval-augmented fact verification framework combining Gemma 3 LLM reasoning with semantic document retrieval (SentenceTransformers, FAISS). Proposed an adaptive convergence strategy that mathematically terminates iterative retrieval once semantic similarity stabilizes[cite: 1].

Quantitative Results
  • Improved the FEVER benchmark by 8% Precision and 10% F1-score through optimized cross-document evidence aggregation[cite: 1].
  • Successfully reduced unnecessary inference steps while preserving prediction quality[cite: 1].
My Contribution

Solely designed and implemented the adaptive convergence algorithm and semantic similarity scoring pipeline.

Limitations & Future Work

Currently constrained to textual evidence. Future iterations will investigate multimodal claim verification (e.g., verifying text claims against retrieved images).

PHORENSICS: Physics-Based Deepfake Detection

RQ: Can we mathematically isolate generative AI synthesis artifacts using physics-based signal processing priors rather than purely semantic models?
[PIPELINE] FFT -> ELA -> PRNU ANALYSIS
[KERNEL] EXTRACTING SENSOR PATTERN NOISE
Problem

Existing deepfake detectors overfit to semantic biases in training data and lack interpretability, making them untrustworthy for high-stakes forensic analysis.

Method

Developed an open-source Python framework integrating frequency-domain analysis via Fast Fourier Transforms (FFT), Error Level Analysis (ELA), and sensor pattern noise (PRNU) to identify generative synthesis artifacts[cite: 1].

Results
  • Achieved a perfect 10/10 grade as my M.Tech Dissertation[cite: 1].
  • Demonstrated high interpretability by surfacing mathematical anomalies rather than relying on black-box neural classifications.
My Contribution

Sole architect. Built a distributed processing framework using Docker and PySpark for scalable analysis, and engineered a fault-tolerant pipeline that dynamically switches between GPU and CPU computation[cite: 1]. Published to PyPI.

TxtVis: Multimodal Representation Geometry

RQ: How can interactive visualization tools assist researchers in understanding the latent geometric evolution of multimodal embeddings during training?
Problem

The optimization dynamics and geometric separation of latent representations in multimodal spaces are difficult to track interactively, hindering model interpretability.

Method

Implemented Skip-Gram embeddings and a custom Siamese Convolutional Neural Network trained with Contrastive Loss. Engineered a from-scratch PyTorch backend connected to an interactive Streamlit UI[cite: 1].

Contribution & Results

Designed the UI/UX to prioritize human-centered interpretability, allowing researchers to monitor PCA projections and embedding evolution dynamically during active optimization[cite: 1].
