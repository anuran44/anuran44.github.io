PHORENSICS: Physics-Inspired Forensics

Combating Misinformation via Global Spectral Analysis & Sensor Noise

Signal Processing & Statistical Formulation

To establish a deterministic boundary between authentic media and deepfakes, I formulated an Unbiased Physics Forensics Framework. Rather than relying on black-box neural networks, the system implements Global Spectral Analysis utilizing Fast Fourier Transforms (FFT) to extract Power Spectrum decay slopes (α), isolating generative upsampling anomalies.

Method & Scalable Execution

For localized manipulations, the architecture processes Local Spatial Statistics, extracting Photo-Response Non-Uniformity (PRNU) and Error Level Analysis (ELA). The detection thresholds are modeled using robust non-parametric statistics, specifically Modified Z-Scores derived via Median Absolute Deviation (MAD). To handle high-resolution matrices without memory failure, I engineered a distributed compute engine using Apache Spark.

BEN-RS-ANN: Speech & Sentence Emotion

Bridging NLP and Speech Signal Processing for Resource-Scarce Environments
INITIALIZE_ANALYSIS
Auditory & Textual Processing

Developing human-centered AI in resource-scarce languages requires innovative architectures. I contributed to the development of a multi-modal approach for revealing emotion from Bengali text and synthesized speech signals. The framework directly tackles polysemous word ambiguity by aligning textual sentiment with frequency domain extractions from acoustic environments.

Methodology

By implementing a custom Resource-Scarce Artificial Neural Network (RS-ANN), the model maps complex speech and text representations efficiently. The framework was evaluated under rigorous 10-fold cross-validation, achieving robust classification accuracy while remaining highly lightweight for public deployment.

Adaptive Social AI Fact Verification

Optimizing Retrieval-Augmented NLP Systems for Human Fact-Checkers
Problem & Motivation

Algorithmic text generation degrades factual ecosystems. Static RAG pipelines often overwhelm users with redundant documents. I addressed this critical human-AI interaction bottleneck by applying statistical thresholds to semantic retrieval.

Method

Combining Gemma 3 LLM reasoning with an adaptive semantic algorithm, the system mathematically terminates iterative retrieval once semantic similarity stabilizes. This presents human moderators with concise, verifiable claim-evidence pairs, significantly reducing cognitive load.
